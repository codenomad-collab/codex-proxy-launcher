# 0.3.1 流量采集修复与实机验证

验证与安装：2026-11-11；归档：2026-11-12（Asia/Shanghai）。被测版本：0.3.1，build 4。

结论：**F-01 已修复并安装，实时速率、曲线及会话累计已恢复实际更新**。这不代表此前未通过的浏览器页面、兼容模式各恢复路径已一并通过。

## 修复内容

- 进程树排序后按最多 20 个 PID 分批调用 nettop，合并所有成功批次，并过滤不属于该批的行。
- 记录系统命令退出状态；进程发现失败、任一批失败、输出不含预期 CSV 标头均记为采集异常，丢弃部分结果。
- 主窗口和菜单栏速率显示“—”并给出异常提示，不把命令失败显示为真实零速率。
- 异常期间保留累计值和上次有效基线；恢复后按完整间隔计算速率，补计仍可观察到的同一进程的字节增量。
- 刷新与周期采样避免重入，曲线不追加失败的假零值，并移除超过三分钟的旧数据。
- 启动时将网络诊断和管理员授权等待放在独立任务中，避免阻塞流量循环。原先保存的兼容模式偏好继续按既有逻辑处理。

主要文件：`TrafficSampler.swift`、`TrafficSamplerTests.swift`、`LauncherViewModel.swift`、`LauncherView.swift`。应用版本、README 和 CHANGELOG 同步为 0.3.1。
